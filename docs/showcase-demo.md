# Five-minute technical demo script

1. Show a clean checkout running the quick reproducibility check and display the
   fixture hashes.
2. Ingest one PDF and show stable extraction/chunk identities.
3. Run an exact identifier query and inspect BM25, dense, RRF, and reranker ranks.
4. Compare conflicting 2025/2026 regulations without mixing scopes.
5. Ask an unanswerable wrong-revision question and show abstention.
6. Retrieve the adversarial bulletin and show that its embedded instruction is
   treated as untrusted evidence.
7. Open Jaeger to inspect the pipeline waterfall and Grafana to show latency and
   queue state.
8. Finish on the held-out ablation dashboard and one failure-atlas case, explaining
   what was rejected and why.
